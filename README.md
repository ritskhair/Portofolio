# DRACO Portfolio — Muhammad Harits Khairiansyah

Personal portfolio website for Automation & IoT Engineering.

**Theme:** DRACO — Dark Industrial, Blue Electric + Orange Fire  
**Stack:** HTML5, CSS3, Vanilla JavaScript (zero dependencies)  
**Hosting:** GitHub Pages

## Sections
- Hero with DRACO aura photo effect
- About & Stats
- Work Experience Timeline
- Project Showcase
- Technical & Soft Skills
- Certificates & Achievements
- Contact Links

## Assets
- `assets/images/` — Profile photo, project images, certificates
- `assets/documents/` — CV/Resume (downloadable)

## Deploy
Push to `main` branch → Enable GitHub Pages in Settings → Pages → Source: main branch.
